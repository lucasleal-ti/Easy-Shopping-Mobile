## 📚 Sobre o Projeto

Esse projeto foi desenvolvido durante meus estudos no **DevClub**, com o objetivo de praticar:

- Estruturação semântica com HTML
- Estilização moderna com CSS
- Organização de layout
- Responsividade com Media Queries

A proposta é apresentar uma landing page simples e moderna para um aplicativo de compras mobile.
